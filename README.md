# ocr2epub

OCR 扫描书籍转 EPUB 电子书的自动化处理流水线工具。

## 项目简介

ocr2epub 用于将 OCR 识别后的扫描书籍文本转换为规范的 EPUB 格式电子书，实现了完整的书籍处理流程，包括脚注重编号、章节检测与分割、目录识别、页码去除等功能。

## 功能特性

- **脚注重排**：自动识别和重排书中脚注，支持多种脚注样式
- **章节检测**：智能识别书籍章节结构，支持自动检测和手动指定
- **目录识别**：自动从目录页提取章节标题，支持模糊匹配
- **页码处理**：三检测器独立判定（页眉聚类 / 独立数字流 / 页首流），页内位置分类（页首奇/页首偶/页脚/页中各流独立验链），附着式页码-眉行三闸整删，形态字典外置可维护
- **EPUB 生成**：输出标准的 EPUB 格式电子书，支持封面、目录、正文、脚注
- **批量处理**：支持批量转换多本书籍

## 核心模块

| 文件 | 功能说明 |
|------|----------|
| `batch_run.py` | 批量处理入口脚本（调度、汇总，不含判定逻辑） |
| `make_epub.py` | EPUB 文件生成，包含标题提取、章节分割、链接器 |
| `renumber_footnotes.py` | 页眉/页码/注释区判定与删除的唯一主体（三检测器、三闸剥离、裸眉清扫） |
| `toc_mark_chapters.py` | 切页（\f 标记）与章节标记（<<<CHAPTER>>>）注入，只标记不删改 |
| `sup_note_prep.py` | 上标/圈码标记转换（页首尾数字化限署名注尾形态） |
| `folio_edge_forms.json` | 页码边缘形态字典（维护点：新书格式加条目，不改判定代码） |
| `diag2.py` | 章节页面诊断工具 |
| `代码规范.md` | 设计/审查门槛（职责矩阵、判定纪律、四件套验收），改动前必过 |

> `strip_folio.py` 已撤销（v0.9h 起）：形态盲删无独立判断能力，功能由
> renumber 内的序列判定全量接管，案卷见 代码规范.md 变更日志第 1 案。

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

### 批量处理

```bash
python batch_run.py 输入目录 输出目录
```

输入目录需包含 `book.titles.txt`（标题文件）和 `book.frontpages`（前言页配置）。

### 单独使用各模块

**生成 EPUB：**
```bash
python make_epub.py --help
```

**页眉/页码/脚注重排：**
```bash
python renumber_footnotes.py --help
```

**切页与章节标记：**
```bash
python toc_mark_chapters.py --help
```

### 重要提示

- 关于 `--inline` 模式与默认模式的区别，请参阅 [HANDOFF.md](./HANDOFF.md) 第 12 节。
- **任何改动（含一行补丁）先过 `代码规范.md` 第 5 节审查清单**；页码类新需求改
  `folio_edge_forms.json` 字典条目，不改判定代码。
- 批处理某本书页码/页眉清不干净时，先看 `.debug.log` 里 `[PAG]` 的拒判 WARN
  （候选数/链长/覆盖率），可自定位是哪一层、为什么拒判。
